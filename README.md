⚡ JEE Tracker Pro (Ultimate Date-Wise Routine, Syllabus & Mock Test Companion)
A clean, fast, 100% offline-first Progressive Web App (PWA) customized specifically for IIT-JEE (Main & Advanced) aspirants.
🌟 Key Highlights & Feature Guide
1. 📅 Date-Wise Daily Routine & Timetable Planner
Plan Tomorrow Today: Switch between Today, Tomorrow, or Pick Any Date using the date navigation bar.
Date-Specific Slots: Custom slots, changes, and checklist completions are saved independently per date.
Instant Topper Presets: Load 12-Hour Focused Dropper, 6-8 Hour School-Going, or Weekend Marathon routines into any selected date with a single tap.
Live Slot Tracking: For today's date, real-time clock monitoring automatically highlights your active ongoing slot.
2. 📚 Clean, Intuitive Official Syllabus Matrix
75 Comprehensive Chapters categorized by Physics, Chemistry (Physical, Inorganic, Organic), and Mathematics with Class 11/12 and High-Yield Weightage tags.
Clear Chapter Progress Bars: Shows exact completion percentage (e.g. 5/7 stages = 71%).
Simple 7 Milestone Checkboxes:
📖 Theory & Lectures
📝 Short Notes Made
🎯 DPP Practice / Level 1
🔥 5-Year PYQs
💎 10-Year PYQs
🔄 Revision 1
⚡ Revision 2
🏆 Chapter Mastered
3. 🎯 Fast Question Solving Station (+1 and -1)
Directly increment (+1, +5) or decrement (-1) question counts for Physics, Chemistry, and Mathematics.
Clear daily goal tracking toward the 100+ questions/day milestone with an option to reset daily counts.
4. 📝 Comprehensive Mock Test Tracker & Mistake Notebook
Detailed Test Logger: Log Test Name, Date, Type (Full Syllabus 300m / Part Test / Subject Test), Physics Marks (/100), Chemistry Marks (/100), Maths Marks (/100), Correct Qs, Wrong Qs (Negative Marks), Unattempted Qs, and Weak Chapters Remarks.
Performance Summary Scorecard: Live calculation of Total Tests Given, Average Score, Highest Score, and Accuracy Rate %.
Mistake Notebook: Log question errors categorized by Calculation Error, Formula Forgotten, Question Misread, Conceptual Gap, Time Rush, or Silly Guess with key takeaway rules.
5. 📊 Simple, Understandable Statistics & Study Reflection
All-time questions solved across Physics, Chemistry, and Mathematics.
Overall syllabus mastery counts (e.g. 45/75 chapters mastered).
Daily Productivity Rating (1–5 ⭐) and reflection notes for continuous self-improvement.
6. 💾 100% Offline PWA & Safe Backup
Runs completely offline via Service Worker caching.
Full JSON Export and Import to easily back up or transfer your study data across devices.
